# round-04 — 스펙 대조 (4차 증분: 별 문턱 Jeans 조건)

커밋 `a7fb94e` · 브랜치 `feat/star-lifecycle` · **메인 실행**(서브에이전트 금지 세션)

## 충족 (2)

| 스펙 항목 | 근거 |
|---|---|
| 가스가 뭉치면 별이 되어 빛난다 | `kCountStars` 로 실제로 센다. 3초에 760,527개 |
| 문턱이 손으로 정한 숫자가 아니라 Jeans 조건 | `kStarForm` 의 `if (cnt > kJeans * s2)` — 상수가 `starJeansK` 하나뿐 |

**Jeans 를 격자에서 정리하면 한 줄이 된다:**

```
M_J = k·σ³/√ρ  이고  M_local = ρ·V (칸 부피 V 고정)
ρV > k·σ³/√ρ  →  ρ^1.5 > k'σ³  →  ρ > k_J·σ²
```

차가우면 낮은 밀도에서도 뭉치고 뜨거우면 더 빽빽해야 한다. **재가 쌓인 자리는 잘 식어
σ 가 내려가므로 문턱이 저절로 낮아진다** — 「재가 많으면 작은 별」이라는 줄을 코드에
적지 않아도 그 사슬이 돈다(원칙 1 이 여기서 값어치를 낸다).

## 곁들여 고친 것 — `kCool` 의 분산 0 버그

**이웃이 하나뿐인 알갱이가 분산 0 을 격자에 쌓고 있었다.**

```
used = 1 일 때:  σ² = sqx/1 − mx²  =  ax² − ax²  =  0
```

표본이 하나면 흩어짐을 잴 수 없다는 통계의 사실이 식에 그대로 드러난 것인데, 그 0 이
격자에 들어가면 **그 칸의 압력과 별 문턱이 함께 0 으로 내려간다.**
`used >= 2` 조건과 표본분산(n−1)으로 고쳤다.

**이 수정은 별 100% 문제를 풀지 못했다**(고친 뒤에도 100%). 다만 **독립적으로 옳은
수정이라 되돌리지 않았다** — 통계적으로 n 이 아니라 n−1 이 맞고, 이웃 하나로 잰 분산 0 은
어떤 경우에도 격자에 들어가면 안 된다. CLAUDE.md 규칙 9.4(가설 실패 시 일부를 남기려면
독립 검증 필요)에 해당하므로 **사용자에게 보고하고 판단을 받을 항목으로 `report-review-me.md`
에 올린다.**

## 미충족 (1) — 「별 비율 5% 안팎」

| 경과 | 별 | 비율 |
|---|---|---|
| 3초 | 760,527 | **76.05%** |
| 10초 | 843,571 | 84.36% |
| 25초 | 957,431 | 95.74% |
| 60초 | 999,393 | **99.94%** |

**두 가지가 겹쳐 있다.**

1. **누적** — 별이 되돌아갈 길이 없다(`p.w != 0` 이면 판정을 건너뛴다). 2스텝마다 판정하므로
   60초면 1800번이고, 매번 조금씩만 통과해도 결국 전부 별이 된다
2. **문턱이 낮다** — 3초에 이미 76% 다. 냉각이 세서 σ² 가 0.0005 까지 떨어지고 빠르게
   뭉쳐, 뭉친 곳이 전부 조건을 넘는다

**세기 조절로 풀 문제가 아니다.** `starJeansK` 를 2,000 → 2,000,000 으로 **1000배** 올려도
전부 100% 였다. 냉각률을 0 까지 낮춰 σ² 를 190배 키워도 100% 였다.

**둘 다 같은 곳에서 풀린다** — 실제 은하도 별 형성률과 사망률이 균형을 이뤄 비율이
유지된다. 지금은 사슬의 절반(수명·폭발)이 없어 **평형이 존재할 수 없다.**
별 형성만으로 5% 를 만들려는 것은 물리적으로 틀린 접근이다.
