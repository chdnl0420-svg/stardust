# 설계 — nbody-simulator

앞 칸: [requirements.md](requirements.md) · [handoff.md](handoff.md) · 방법 선정 근거: [method-search/scorecard.md](method-search/scorecard.md)
**UI 시안 겸 동작 프로토타입: [design-mockup.html](design-mockup.html)** — 구현은 이 파일을 열어 보고 만든다.

UI 갈래: **데스크톱 앱** (유니티 NGUI 아님, 웹 아님)

---

## 1. 무엇을 만드는가

Windows 데스크톱 앱 하나. 창을 띄우면 2D 파티클이 중력과 가스 압력으로 움직이고,
오른쪽 설정 보드에서 모든 물리 기능을 켜고 끄고 수치를 조절하며, 마우스로 돌아가는 중에 개입한다.

## 2. 기술 스택 (확정)

| 층 | 선택 | 근거 |
|---|---|---|
| 계산 | **CUDA 13.3** + cuFFT + CUB | 실측 선정 (scorecard.md). WebGPU 대비 산란 3배 |
| 창 | **Win32** (Windows SDK 10.0.26100) | 외부 의존성 0. GL.h·opengl32.lib 존재 확인 |
| 렌더 | **OpenGL** + `cuda_gl_interop` | 헤더 존재 확인. 계산 결과가 GPU 메모리에서 화면으로 직행 — CPU 왕복 없음 |
| UI | **Dear ImGui** (vendoring, git clone) | 새로 받는 유일한 의존성. 슬라이더·체크박스·접힘 패널이 설정 보드 요구에 정확히 맞음 |
| 빌드 | **CMake 4.4.2** + MSVC 2022 | 설치 확인 |

빌드 플래그(실측으로 확정): `-std=c++17 -arch=sm_86 -Xcompiler "/Zc:preprocessor /utf-8 /std:c++17"`
CUDA 13 은 DLL 이 `bin\x64\` 에 있고 `cudaDeviceProp::memoryClockRate` 가 제거됐다.

## 3. 모듈 구성

```
src/
  main.cpp            Win32 창 + 메인 루프 + ImGui 프레임
  app/
    App.h/.cpp        상태 소유, 설정 보드 값 <-> 시뮬레이션 파라미터 연결
    Settings.h        모든 토글·수치의 단일 구조체 (직렬화 가능)
    Presets.cpp       프리셋 5종 정의 (경계·압력·팽창을 함께 설정)
    Recorder.cpp      PNG 시퀀스 저장
  sim/
    Sim.h/.cpp        파이프라인 오케스트레이션, 버퍼 소유
    kernels.cu        산란·보간·적분·압력·온도·냉각·별형성
    poisson.cu        cuFFT 포아송 (주기 / 고립 zero-padding 두 경로)
    sort.cu           CUB radix sort + 재배치
    brush.cu          마우스 도구 (뿌리기·우물·형태추가·지우개)
  gfx/
    GLContext.cpp     wgl 컨텍스트 생성
    Interop.cpp       CUDA <-> GL 버퍼/텍스처 등록
    RenderField.cpp   밀도 텍스처 + 컬러맵 셰이더
    RenderPoints.cpp  파티클 점 렌더 (가산 블렌딩)
  ui/
    Board.cpp         설정 보드 9섹션 (시안 그대로)
    Hud.cpp           좌상단 오버레이
    Toolbar.cpp       하단 도구 툴바
```

한 파일 200~400줄을 넘기지 않는다.

## 4. 한 프레임의 데이터 흐름

```
[CPU] ImGui 입력 → Settings 갱신
   ↓
[GPU] (K스텝마다) cellKey → CUB radix sort → reorder
   ↓
[GPU] clearGrid → CIC 산란(atomicAdd float) → 밀도 격자
   ↓
[GPU] 중력: 주기면 FFT(1/k) / 고립이면 zero-padding + 실공간 그린함수
   ↓
[GPU] 가스: 압력 P=Kρ^γ → 온도 갱신 → 냉각 → 별형성 판정
   ↓
[GPU] 격자 가속도 = -∇φ + (-∇P/ρ)
   ↓
[GPU] CIC 보간 → 속도·위치 적분 (dt 는 CFL 클램프)
   ↓
[GPU] interop: 밀도 격자 → GL 텍스처 / 파티클 버퍼 → GL VBO
   ↓
[GL ] 밀도 필드 또는 점 렌더 → ImGui 오버레이 → SwapBuffers
```

**정렬은 매 스텝이 아니라 K스텝마다** 한다(기본 K=40). 실측 근거: 40스텝까지 성능 유지, 80에서 3배 악화.
정렬은 정확성이 아니라 캐시 지역성 목적이라 건너뛰어도 결과가 틀리지 않는다.

## 5. 열린 질문 8개 — 해소

| # | 질문 | 결정 | 근거 |
|---|---|---|---|
| O1 | 설정 보드 구성 | **9섹션 고정**: 시뮬레이션·중력·가스·우주·표시·마우스 도구·프리셋·녹화·성능. 접힘 상태 기억 | [design-mockup.html](design-mockup.html) 에서 확정 |
| O2 | 별 형성 기준 | **밀도 임계 AND 온도 임계** 둘 다 만족 시 파티클을 '별' 플래그로 전환. 별은 압력 계산에서 제외되고 중력만 받는다(= 충돌 없는 물질) | 실제 은하 형성 코드의 표준. 두 조건 중 하나만 쓰면 뜨겁고 조밀한 충격파면에서 오검출 |
| O3 | 냉각 함수 | **단순 멱함수** `Λ = coolRate · ρ · T^α` (α=0.5 기본). 냉각 테이블 미사용 | 외부 데이터 의존성 0. 슬라이더로 조절 가능해 실험 도구 성격에 맞음 |
| O4 | 녹화 형식 | **PNG 시퀀스만.** 동영상 인코더를 앱에 넣지 않는다 | 의존성을 늘리지 않기 위해. 합치기는 외부 도구 몫 |
| O5 | 마우스 도구 | **5종**: 카메라(줌·팬) / 가스 뿌리기 / 중력 우물 / 형태 추가 / 지우개 | 시안에서 확정. 형태는 회전원반·정지덩어리·가스고리 3종 |
| O6 | 창 해상도 | 기본 **1600×900**, 자유 리사이즈. 렌더 타깃은 창 크기를 따르고 격자 해상도와 독립 | 격자를 바꿔도 창이 안 흔들려야 한다 |
| O7 | 온도 색 매핑 | 색 기준 드롭다운(밀도/온도/속도) × 컬러맵(천체/흑백/열화상). **온도는 열화상이 기본 조합** | 충격파면이 붉게 서는 것이 목적이라 열화상이 직관적 |
| O8 | 전 기능 60FPS | 아래 §6 예산 배분. **구현 중 실측으로 검증**하고 초과하면 격자 해상도 자동 강등 | 온도·냉각·별형성 비용이 미측정 상태 |

## 6. 성능 예산 (N=1000만, 2048², 60FPS = 16.7 ms)

| 단계 | 예산 | 근거 |
|---|---|---|
| 단계 | 예산 | 근거 |
|---|---|---|
| 산란 | 0.6 ms | 실측 0.593 |
| 포아송 — 주기 경계 | 0.5 ms | 실측 0.495 |
| 포아송 — 고립 경계 | 2.4 ms | 실측 4096² 2.361 (패딩 격자). 주기와 **택일**이다 |
| 보간 + 적분 | 0.9 ms | 실측 0.817 |
| 정렬 (K=40 분할) | 0.2 ms | 실측 6.84 / 40 |
| 가스(압력·온도·냉각·별형성) | **3.0 ms** | **미측정 — 격자 순회 4패스 추정** |
| 렌더 + ImGui | 2.5 ms | 미측정 |

| 경우 | 합계 | 여유 |
|---|---|---|
| 주기 경계 (구조 형성) | **7.7 ms** | 9.0 ms |
| 고립 경계 (은하) | **9.6 ms** | 7.1 ms |

여유가 7 ms 이상 남지만 가스 4기능이 미측정이라 이 칸이 어긋나면 예산이 흔들린다.
**초과 시 대응**: 격자 해상도를 한 단계 낮추고 HUD 에 경고를 띄운다. 사용자가 기능을 끄면 그만큼 회복된다.

## 7. 에러 처리

| 상황 | 처리 |
|---|---|
| CUDA 장치 없음 / 초기화 실패 | 창에 안내를 띄우고 종료. 조용히 죽지 않는다 |
| VRAM 부족 (파티클 수 과다) | 요청 직전 가용량을 확인해 최대 가능 수로 클램프하고 보드에 알린다 |
| CFL 위반 (dt 과대) | 매 스텝 dt 를 `min(dt, C·cell/max|v|)` 로 클램프. 서브스텝 상한 4회 |
| 밀도 0 셀에서 압력 나눗셈 | `max(ρ, ε)` 로 하한 |
| 파티클이 경계 이탈 | 고립이면 클램프 + 속도 감쇠, 주기면 wrap |
| 셰이더/커널 컴파일 실패 | 빌드 타임 실패로 잡는다 (런타임 컴파일 없음) |

## 8. 테스트 방식

| 층 | 방법 |
|---|---|
| 물리 정확도 | 직접 O(N²) 대비 힘 오차 RMS. 이미 프로토타입에 있음(`proto/cuda/x3.cu`). **판정선 0.15** — 근거: 고립경계 실측이 소프트닝을 셀에 비례시킨 조건에서 256² 0.077 / 512² 0.134 / 1024² 0.207 / 2048² 0.259 였다(measurements.md 라운드5). 실사용은 소프트닝을 3셀 이상으로 잡아 오차가 이보다 작아지므로, 512² 실측값(0.134)에 여유를 얹은 0.15 를 문턱으로 둔다. 넘으면 소프트닝 또는 격자 해상도를 조정한다 |
| 보존량 | 총 질량·질량중심이 장시간 보존되는지. **프로토타입에서 이미 확인** (299,854 → 299,854, 중심 0.500→0.496) |
| 기능 토글 | 각 토글 on/off 로 밀도 통계가 달라지는지 정량 비교. **프로토타입에서 확인** (중력 0 → 최대밀도 154.6 / 중력 0.6 → 1001.7) |
| 시나리오 | 프리셋 4종이 각각 의도한 현상을 만드는지 스크린샷 |
| 성능 | HUD 의 단계별 ms 를 파티클 수·격자별로 기록 |

## 9. 프로토타입에서 미리 드러난 것 (구현이 반영할 것)

1. **형태 추가 시 다음 빈 슬롯부터 꺼내야 한다.** 프로토타입은 앞에서부터 스캔해 이미 쓴 구간을 건너뛰는 바람에
   두 번째 추가에서 요청보다 적게 나왔다(16만 요청 → 8만 추가). 자유 슬롯 커서를 두고 거기서부터 꺼낸다.
2. **강한 중력에서 고정 dt 는 무너진다.** 중력 1.5에서 오히려 덜 뭉쳤다(최대밀도 296.7 < 0.6일 때 1001.7).
   파티클이 튕겨 나간 것이라 CFL 클램프가 필수다.
3. **압력 효과가 약했다.** 압력을 켜도 최대밀도가 296.7 → 285.2 로 조금만 줄었다.
   압력계수를 중력 스케일에 맞춰 보정하는 작업(requirements B4)이 실제로 필요함이 확인됐다.
4. **렌더는 읽기 전용 바인딩이 따로 필요하다.** 같은 버퍼를 쓰기용과 읽기용으로 한 패스에 걸면 거부된다.
   CUDA-GL interop 에서도 매핑/언매핑 순서를 지켜야 한다.

## 10. 이번 설계가 손대지 않는 것

- 3D · 파티클 두 종류 · 강체 충돌 (요구사항 G 에서 제외 확정)
- Barnes-Hut · 멀티그리드 · PM+SPH (실측 탈락, scorecard.md)
- 초신성 피드백 (별 형성까지만)
- 크로스플랫폼 (Windows 전용)
