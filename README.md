# Stardust

알갱이 수백만 개가 서로 중력으로 끌어당기며 실시간으로 움직이는 것을 보는 프로그램입니다.
은하가 나선 팔을 만들고, 두 은하가 스치며 꼬리를 남기고, 가스가 뭉쳐 소행성이 됩니다.

계산은 전부 그래픽카드가 합니다.

## 설치

[최신 릴리스](../../releases/latest)에서 `Stardust-x.y.z-setup.exe` 를 받아 실행하세요.

설치는 사용자 폴더(`%LOCALAPPDATA%\Stardust`)에 되므로 관리자 권한이 필요 없습니다.

## 필요한 것

| | |
|---|---|
| 운영체제 | Windows 10 이상 (64비트) |
| 그래픽카드 | **NVIDIA 지포스 GTX 10 시리즈 이상** |
| 그래픽 드라이버 | 최신 버전 권장 |

**NVIDIA 그래픽카드가 반드시 필요합니다.** 계산에 CUDA 를 쓰기 때문에 AMD·인텔 내장 그래픽에서는
실행되지 않습니다.

알갱이를 몇 개까지 둘 수 있는지는 그래픽카드에 따라 다릅니다. 앱이 켜질 때 카드를 보고
상한을 스스로 정하고, 돌아가는 중에도 버거우면 개수를 낮춥니다.

## 무엇을 할 수 있나

- **장면 고르기** — 나선 은하 · 은하 충돌 · 정면 충돌 · 우주 거미줄 · 블랙홀 · 뭉치기 · 빈 우주
- **직접 놓기** — 은하 · 태양 · 고리 · 구름 · 덩어리 모양을 화면에 클릭해 뿌리기
- **알갱이끼리 부딪히게** — 켜면 서로 통과하지 못하고 뭉쳐 덩어리가 됩니다
- **시간 조절** — 멈춤 · 처음부터 · 빠르기 0.1~10배
- **보기** — 밀도로 볼지 온도로 볼지, 밝기와 대비
- **녹화** — 한 장 저장 또는 연속 녹화
- `Tab` 키로 설정을 모두 감추고 화면만 볼 수 있습니다

## 자동 업데이트

앱을 켤 때 이 저장소의 최신 버전을 확인합니다. 새 버전이 있으면 설정 보드에 알림이 뜨고,
**직접 누를 때만** 받습니다. 받는 것은 1.2 MB 짜리 실행 파일 하나뿐입니다.
